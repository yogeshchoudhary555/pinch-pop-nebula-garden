# Pinch Pop: Nebula Garden

A hands-first, seated WebXR game built with Meta's Immersive Web SDK (IWSDK) for the **Meta VR Start Developer Competition 2026** — Track: Gaming, Division: New Experience.

Glowing nebula orbs drift within arm's reach. **Pinch an orb to pop it** — pop the color shown on the target ring to build combos and bank points. Wrong-color pops break the combo. 3-minute rounds, escalating waves, best score and day streak saved between sessions.

**Play:** https://yogeshchoudhary555.github.io/pinch-pop-nebula-garden/

Works on Meta Quest (hand tracking) and in a desktop browser via the IWSDK XR Simulator / IWER emulation (gaze-dwell + click fallback included). Free, no install.
